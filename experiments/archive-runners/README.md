# Исходные скрипты записанных экспериментов

Здесь сохранён код подготовки, запуска, ограниченного API-прокси, восстановления и экспорта первоначальных записей. Личные пути заменены на `/home/demo` и `/demo`, ключей в комплекте нет.

Эти файлы оставлены для изучения устройства исходного измерения. Не запускайте их буквально: они привязаны к структуре первоначального стенда. Переносимые проекты для нового запуска находятся в `templates/`, а инструкции — в `docs/LIVE-API.md`. Воспроизведение готового опыта выполняется корневым лаунчером.
