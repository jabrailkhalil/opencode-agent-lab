# PDF-гайды

- [Настройка API и моделей с обведёнными элементами](OpenCode-API-Setup-Annotated.pdf) — 4 страницы: актуальная последовательность настройки и три исходных скриншота (проект, ключ OpenRouter, роль и отправка). Настоящих ключей в документе нет. Доступен отдельно по /setup.pdf.

- [Актуальные схемы и пошаговый гайд](OpenCode-Guide-with-Workflows.pdf) — 52 страницы: сначала 11 страниц с методологией, точным порядком обращений, входами и выходами четырёх современных веток; затем исходная инструкция по кликам.
- [Исходная инструкция от 7 октября](OpenCode-Step-by-Step-2026-10-07.pdf) — 41 страница, сохранена отдельно без изменений.

Полный гайд открывается первой кнопкой на главной странице и по /guide.pdf. В начале показаны spec-driven и адресная передача заданий; у каждой записи своя последовательность ролей. Браузерные наблюдения оператора, незаписанные QA-отчёты и дополнительные UI-итерации обозначены отдельно.

Исходная часть от 7 октября содержит примеры прежних папок и портов. Для переноса используйте [инструкцию установки](../LAPTOP-SETUP.md), [актуальную памятку по кликам](../CLICK-GUIDE.md) и [пояснение схем](../WORKFLOWS.md).
