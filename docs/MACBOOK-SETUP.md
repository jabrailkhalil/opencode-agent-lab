# Перенос на MacBook

Комплект подготовлен для macOS на Apple Silicon и Intel. Лаунчер выбирает установленную нативную сборку OpenCode по метаданным пакета, хранит все рабочие пути относительно каталога проекта и запускает только localhost. Windows-пути переносить не нужно.

## Что переносить

Скачайте свежий ZIP с GitHub или клонируйте репозиторий. **Не копируйте `node_modules`, `.runtime`, API-ключи и сессии с Windows.** Зависимости ставятся заново для архитектуры Mac; чекпоинты, PDF и экспериментальные данные уже находятся в репозитории.

Нужны обычный браузер и Node.js 22.14+ или 24 LTS с [официального сайта](https://nodejs.org/en/download). Отдельные OpenCode, Python, Docker и ключи для записи не нужны. Интернет нужен при первой установке npm-пакетов.

## Первый запуск

1. Распакуйте ZIP в отдельную папку, например `Documents/OpenCode Lab`.
2. Откройте **`INSTALL-MAC.command`**. Он устанавливает закреплённые зависимости, сверяет снимки, запускает тесты и проверяет окружение.
3. Откройте **`START-MAC.command`**. Откроются главная страница, два пульта и общее окно OpenCode.
4. В общем окне нажмите **«Начать оба с нуля»**. Дождитесь `0 / 11` и пустых чатов, затем «Вставить оба промпта» → «Отправить оба».
5. Для остановки откройте **`STOP-MAC.command`**.

Если после распаковки `.command` не запускаются из Finder, откройте Терминал в папке проекта и выполните:

```bash
chmod +x INSTALL-MAC.command START-MAC.command STOP-MAC.command
bash INSTALL-MAC.command
bash START-MAC.command
```

Альтернатива через Терминал:

```bash
git clone https://github.com/jabrailkhalil/opencode-agent-lab.git
cd opencode-agent-lab
npm ci
npm run check
npm test
npm run doctor -- --json
npm start -- --open
```

Главная страница: http://127.0.0.1:4201/welcome. Общий старт: http://127.0.0.1:4201/parallel.

## Проверка на целевом Mac

```bash
npm run smoke -- --full
```

Тест проходит оба сохранённых маршрута в настоящем локальном OpenCode, проверяет одиночную отправку, повторный запрос, старый чат и общий сброс. В конце остаются новые пустые чаты. Платных запросов нет.

После теста проверьте в браузере PDF, пять приложений, вставку и отправку кнопками. Автоматическая проверка CI для macOS ARM64 и Intel описана в [workflow](../.github/workflows/verify.yml). Она не заменяет проверку Finder, браузера и корпоративных ограничений на конкретном MacBook.

## Если возникла проблема

- `node`/`npm` не найдены: установите официальный Node.js, откройте новое окно Терминала и повторите установку. Скрипты также учитывают стандартные пути Homebrew.
- Ошибка доступа к npm: проверьте сеть; проверки TLS отключать не нужно.
- Занят порт: `npm run doctor -- --json` покажет состояние. `npm stop` завершает только процессы этой копии с проверкой пути и времени запуска. Чужие процессы не завершайте.
- Эта же копия уже запущена: `START-MAC.command` открывает её, сохраняя прогресс. Перед записью сбрасывайте обе ветки общей кнопкой.
- macOS блокирует скачанный файл: проверьте источник и покажите сообщение агенту на Mac. Не отключайте защиту системы целиком.
- Логи: `.runtime/logs/`. Прошлые рабочие файлы сохраняются в `.runtime/`.

Готовая задача для агента на Mac находится в [AGENT-HANDOFF.md](AGENT-HANDOFF.md). Она просит проверить именно целевой ноутбук, без нового платного прогона моделей.
