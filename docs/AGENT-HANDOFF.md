# Текст для передачи агенту на другом ноутбуке

Скопируйте следующий текст в задачу агента, работающего на целевом ноутбуке:

```text
Настрой на этом ноутбуке комплект https://github.com/jabrailkhalil/opencode-agent-lab.

Сначала прочитай AGENTS.md, README.md и docs/LAPTOP-SETUP.md; на MacBook также docs/MACBOOK-SETUP.md. Определи ОС, архитектуру, Node.js/npm и свободные порты. Установи зависимости закреплённых версий. Если Node.js отсутствует, используй официальный источник и доступные права пользователя. Не переноси node_modules, .runtime и ключи с другого устройства.

Нужен режим воспроизведения готовых чекпоинтов, без платных API-запросов и без ключей. Проверь npm run check, npm test, npm run doctor -- --json, затем запусти интерфейс.

Проверь, что открываются пошаговый PDF, все пять готовых приложений, этапы четырёх современных прогонов и архив Qwen Coder, метрики и два чата OpenCode. Выполни npm run smoke -- --full. В браузере проверь «Начать оба с нуля» → 0/11 и пустые чаты → «Вставить оба промпта» → «Отправить оба». Проверь также «Только слева»: справа не должно отправляться ничего. После проверки верни чистый старт общей кнопкой.

Не меняй сохранённые снимки, не обновляй OpenCode и не останавливай чужие процессы. Исправляй только переносимые настройки и запуск, если потребуется.

В конце дай ссылку на главную страницу, простой способ запуска и остановки, результаты проверок и ограничения именно этого ноутбука.
```

Этот текст ставит задачу настройки окружения. Он не просит заново генерировать приложения и не разрешает расходы API.
