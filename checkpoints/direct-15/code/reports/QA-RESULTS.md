## Замечания (по убыванию важности)
**R1. Средний риск, NOT RUN. Потеря клика после правки доступности.**
`app.js:407-409`: `change` на `capacity-*` вызывает `commit` → `render()`, который заменяет DOM команды и списка задач.
Шаги: ввести новое значение в `capacity-anna` и сразу кликнуть мышью `edit-TASK-101`. `change` сработает между mousedown и mouseup, кнопка будет заменена, и `click` может не дойти.
Проверить в браузере. Исправление: не перерисовывать `#main` при смене доступности, либо обновлять узлы на месте.

**R2. Средний риск, NOT RUN (CSS). Панель «Команда» на ≥1200 px.**
`styles.css:111`: `.team` имеет `position: sticky` и не имеет `max-height` или прокрутки. Четыре карточки сотрудников высотой около 1000+ px могут быть выше окна.
Шаги: окно 1280×720, создать много задач в одной колонке, прокрутить вниз. Нижние сотрудники (нагрузка и прогресс) могут оказаться недоступны, пока не закончится рабочая зона. Это нарушает требование «нагрузка и прогресс каждого сотрудника доступны».
Исправление: `max-height: calc(100vh - 24px); overflow: auto`.

**R3. Низкий. Некорректная доступность сбрасывает ввод и фокус.**
`app.js:348-353`: при ошибке (например 169) вызывается `renderTeam()`. Поле возвращается к прежнему значению, введённое пользователем пропадает, фокус уходит на body (восстановление фокуса есть только в `render()`). Сообщение об ошибке при этом показывается (`role=alert`).

**R4. Низкий. Закрытие формы без предупреждения.**
`app.js:384-386` (клик по подложке) и `app.js:418-420` (Esc) закрывают форму с введёнными данными без подтверждения. Шаги: открыть `new-task`, ввести название, кликнуть вне диалога или нажать Esc. Ввод потерян.

**R5. Низкий. Применение пустого плана.**
`app.js:204`: `plan-apply` получает `disabled`, если распределение совпадает с текущим. Автоматический клик по `plan-apply` в таком случае зависнет по таймауту. На seed изменения есть, кнопка активна.

**R6. Информационно / расхождения с формулировками.**
- Доступность принимает только шаг 0,5 (`app.js:350`). Бриф требует 0–168 без шага. Значение 24,25 отклоняется.
- Выбранная неделя не сохраняется: после перезагрузки показывается 2026-09-28 (в брифе сохранение недели не требуется).
- `monday()` принимает только строку `YYYY-MM-DD`; Date и ISO с временем вызывают `Error` (контракт не уточняет).
- Порядок Tab на ≥1200 px не совпадает с визуальным (известное ограничение разработчика).
