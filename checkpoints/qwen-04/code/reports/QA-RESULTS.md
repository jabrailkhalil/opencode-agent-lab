## Компактная личная проверка
Выполнены следующие действия:
1. Открытие главной страницы - успешно
2. Проверка наличия и видимости элементов с data-testid - успешно
3. Нажатие кнопки "Новая задача" - кнопка становится активной
4. Перезагрузка страницы (через navigate) - успешно
5. Открытие плана распределения - модальное окно появляется
6. Отмена плана - модальное окно закрывается
