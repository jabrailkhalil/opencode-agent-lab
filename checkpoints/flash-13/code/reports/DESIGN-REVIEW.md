# DESIGN-REVIEW — сверка UI-кода с reports/DESIGN-PLAN.md

Режим: code review, браузер не подключён. Визуальный PASS не заявляется. Проверены dist/index.html (99 ст.), dist/styles.css (85 ст.), dist/app.js (292 ст.), dist/domain.js; контракты docs/INTERFACES.md, docs/DESIGN-REFERENCE.md.

## 1. Подтверждено кодом (соответствует плану)
- §1 Нет бокового сайдбара ни на одной ширине: appbar + один `main.container` (index.html:11–43); метрики/доска/сотрудники на всю ширину. «Четыре колонки кнопок рядом с панелью» физически невозможны; footer-actions и toolbar — flex-wrap (styles.css:19,60).
- §2 Нагрузка и прогресс — два отдельных подписанных блока `load-*` / `progress-*`, никогда одна полоса (app.js:81–92). percent=null → «— · нет доступности» (app.js:75); «+N ч» с словом «Перегрузка» красным #d63939 только при overload>0 (app.js:85, styles.css:54); прогресс — зелёная полоса #2fb344 (styles.css:53); totalHours=0 → «0 · нет назначенных часов», NaN нет (app.js:90, domain.js:72).
- §2 capacity-* — number 0–168, сохранение на change и blur, кламп и округление (app.js:86–88, 206–218, 282–283).
- §3 Ошибки: все в alert `task-error` списком `<ul>`, `.is-invalid` + `aria-describedby` на каждом проблемном поле, фокус на первое, значения не сбрасываются (app.js:116–128); порядок ошибок = порядок полей в форме (domain.js:77–91). Формат часы: label «0,5–168, шаг 0,5», hint встроен (index.html:54). Удаление/reset-demo — подтверждение с названием задачи, отмена ничего не меняет (app.js:231, 274).
- §4 Пустые состояния: заглушка колонки + подсказка drag-and-drop, зона остаётся drop-приёмником (app.js:63–69); нет результатов — один alert + кнопка сброса, метрики полной недели не трогает (app.js:61–65, 107); «Изменений нет» → `plan-apply.disabled` (app.js:177, 186).
- §5 plan-preview: apply — единственная точка записи (app.js:190–197), до apply state не меняется; непоместившиеся — красные строки `.unplaced` (styles.css:70); reset-demo вне модалки, внизу страницы (index.html:39–42).
- §7 aria-live на task-error (assertive) и plan-summary (polite) (index.html:49, 77); DOM-порядок форма→ошибки→footer соблюдает tabbed-порядок; Escape закрывает модалки (app.js:284–286); focus-visible на карточках (styles.css:32); overflow-wrap:anywhere на заголовках/чипах/план-строках (styles.css:35–38, 49, 58, 69).
- §6 Брейкпоинты декларативно: метрики 4→2 (≤1100)→1 (≤480); доска 3→1 (≤900, покрывает 768); emp-metrics 2→1 (≤640); на ≤480 weeklabel отдельной строкой, кнопки footer/toolbar/modal — стопка ≥44 px (styles.css:71–84). Колонки min-height 140 ≥ 120 (styles.css:27).

## 2. Замечания, подтверждённые кодом
1. §2/§6: таблица сотрудников на ≥1100 не реализована — `renderEmployees` всегда рисует карточки (app.js:72–96); в app/index.html нет `<table>`. INTERFACES допускает «строки/карточки», но DESIGN-PLAN требовал таблицу с колонками Сотрудник/Загрузка/Перегрузка/Прогресс/Доступность/Задачи на 1280/1100 — отклонение от плана.
2. §2: «перелив — красный участок» полосы загрузки отсутствует: ширина capped `Math.min(100, …)` и всегда синий `.fill` (app.js:76, 84); перегрузка видна только текстом.
3. §6 (390): «edit/delete в карточке ≥44 px» не покрыто — правило min-height:44 распространяется только на .footer-actions/.toolbar/.modal-actions (styles.css:84); кнопки карточек — `btn-sm` без исключения (app.js:54–55, 63).
4. §5: шапка предпросмотра без «(M задач)» и с формулировкой «Не разместилось N ч» (app.js:177); при нулевых изменениях пропавшие часы в сводке не упоминаются вовсе.
5. §3: модалки — самодельный overlay, не компонент Tabler `.modal` (index.html:45–95, styles.css:61–62); на 390 это полотно min(560px,100%) с отступом 16, не «full-screen sheet».
6. §7: нет focus-trap и возврата фокуса открывшему элементу — после закрытия фокус уходит в body; Escape скрывает все модалки разом (app.js:284–286).
7. §1/метки: подписи метрик «Активных задач», «Выполнено часов» длиннее плановых «Активных», «Выполнено» и value «N ч» даёт тавтологию «Выполнено часов: 10 ч» (app.js:41–42) — риск переноса в ячейке 2×2.
8. §6 (768): «search/filter по 100%» — filter задан `flex: 0 1 220px` без роста (styles.css:21), на всю ширину не растягивается.
9. §6 (1100): container фиксированный max-width 1200 (styles.css:9), контент на 1100 ≈1068 вместо плановых 1080 — близко, но не буквально.
