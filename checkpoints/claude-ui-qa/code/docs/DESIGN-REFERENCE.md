# Дизайн

Открытый референс — Tabler Kanban: https://preview.tabler.io/tasks.html . Локальный CSS @tabler/core 1.6.1 и MIT-лицензия заранее находятся в dist/vendor/tabler/.
Нужен компактный рабочий интерфейс: светлая навигация, шапка «План команды», недельные метрики, таблица/карточки сотрудников и канбан. Акцент #206bc4, текст #182433, фон #f6f7f9, границы #e6e8ec, ошибки #d63939, завершение #2fb344.
Перегрузка должна быть числом и подписью; прогресс по выполненным часам — отдельный подписанный показатель. На 390/768/1100/1280 px показатели не исчезают. Ошибка формы видна внутри формы.
Дизайнер Qwen принимает текст: анализировать реальный DOM, подписи, структуру, размеры через браузерные инструменты. Скриншоты сохранять как артефакты, не заявлять о визуальном чтении изображений. До создания UI выдать подробное задание разработчику, после реализации сделать DOM-ревью.
