# Отчёт разработчика: «Поток»

## Что сделано
Созданы четыре файла в `dist/`: `index.html` (каркас, подключает `vendor/tabler/tabler.min.css`), `styles.css` (небольшие дополнения к Tabler, токены из DESIGN-PLAN), `domain.js` (чистая логика), `app.js` (UI на ES-модулях, без зависимостей и внешних ресурсов). Документы, `tests/acceptance.test.mjs` и `dist/vendor` не менялись.

## domain.js
- Экспорты по INTERFACES: `DEMO_WEEK`, `seedState`, `monday`, `loadFor`, `validateTask`, `proposePlan`, `applyPlan`, `isValidState`. Дополнительно: `STATUSES`, `addDays`, `isMonday`, `capacityOf`.
- Даты считаются через UTC, поэтому часовой пояс не влияет.
- `loadFor`: активные часы / доступность, `percent=null` при нулевой доступности, `progress=0` без назначенных часов.
- `validateTask` бросает `Error` с полем `field`, чтобы UI подсветил нужное поле.
- `proposePlan` — жадный алгоритм: крупные задачи первыми, текущий ответственный сохраняется, если задача помещается, иначе берётся сотрудник с наибольшим остатком; не поместилась — `null`. Состояние не мутируется. `applyPlan` меняет только невыполненные задачи из плана.
- `isValidState`: версия, уникальные id сотрудников и задач, формат `TASK-N`, валидность задач и доступностей, `nextId >= 110` и больше максимального номера.

## app.js: пункты брифа
1. CRUD задач: модальная форма, удаление через подтверждение.
2. Доска из трёх колонок, drag-and-drop (`dragstart/dragover/drop`), смена статуса в форме.
3. Вид «По сотрудникам» с переключением; рендерится только активный вид, данные общие.
4. Поиск и фильтр скрывают только карточки. Метрики считаются по всем задачам недели.
5. Навигация по неделям, старт 2026-09-28. Доступность хранится по неделям.
6. Поля `capacity-*` сохраняются на change/blur, значения вне 0–168 или не кратные 0,5 отклоняются, под полем показывается ошибка.
7. `load-*` (часы / доступно, %, перегрузка «+N ч») и `progress-*` — отдельные блоки.
8. Предпросмотр плана: `plan-preview`, `plan-apply`, `plan-cancel`. Состояние не меняется до применения. Любое изменение данных или недели отменяет предпросмотр с уведомлением.
9. localStorage (ключ `potok-state-v1`). Повреждённый JSON или невалидное состояние заменяются учебным примером с предупреждением. Недоступное хранилище не роняет приложение. `reset-demo` требует подтверждения.
10. Ошибка валидации показывается в `task-error` внутри открытой формы, значения не сбрасываются, фокус идёт на неверное поле.
11. Адаптивная сетка под 390/768/1100/1280 (`min-width: 768/1200` + `auto-fit`), панель «Команда» — боковая только от 1200 px. Подписи `label for`, Esc, цикл фокуса в диалогах, `aria-pressed`, `role=alert`.

Добавлены все testid из INTERFACES.md. Дополнительно: `sum-*` для сводки, `confirm-ok`/`confirm-cancel` для подтверждений.

## Исправление D1: слипшиеся даты в `current-week`
**Причина** (подтверждена чтением кода; QA-RESULTS D1, DESIGN-PLAN п. 6.1): `app.js` `renderChrome` выводил в кнопку подпись («28 сен – 4 окт 2026») и через обычный пробел `<span class="text-secondary">` с ISO-датой. В `styles.css` у `.week-current` не было правил для вложенных элементов, поэтому обе даты шли в одной строке, и год подписи читался слитно с ISO.

**Изменение** (только разметка и CSS, логика недель и расчётов не тронута):
- `dist/app.js` `renderChrome`: кнопка получает два span: `.week-label` (подпись) и `.week-iso text-secondary` (ISO). Добавлен `aria-label` «Неделя <ISO>, <подпись>. Вернуться к начальной неделе», чтобы ISO оставалась доступной.
- `dist/styles.css`: у `.week-current` добавлены `text-align:center; min-width:0`. Оба span получили `display:block`. ISO: `font-size:.8125rem` (13 px), `font-weight:400`, `margin-top:2px`.
- `index.html`, `domain.js`, docs, `tests/acceptance.test.mjs`, `dist/vendor` не менялись.

**Результат:**
- `node --check dist/app.js`: без ошибок.
- `node --test tests/acceptance.test.mjs`: 9 из 9, fail 0.
- В браузере не проверялось (NOT RUN): вид кнопки на 390/1280, `getBoundingClientRect`, `innerText` по п. 6.1 DESIGN-PLAN остаются за проверяющим с браузером.

## Известные ограничения
- В DOM панель «Команда» стоит перед доской, поэтому на ≥1200 px порядок Tab не совпадает с визуальным.
- Кнопка `current-week` возвращает к начальной неделе 2026-09-28.
- Опция «Без ответственного» в фильтре имеет значение `none` (дополнение к контракту).
