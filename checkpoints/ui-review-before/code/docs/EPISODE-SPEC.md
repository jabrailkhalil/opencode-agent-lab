# UI-ревью панели управления

На 390, 768, 1100, 1280 и 1920 px подписи действий должны помещаться в свои кнопки и не перекрывать соседние. Проверяются «Доска», «По сотрудникам», «Предложить распределение». Макет проверяется целиком после добавления правой колонки. Расчёт нагрузки и прогресса, сохранение данных и перетаскивание сохраняются.
