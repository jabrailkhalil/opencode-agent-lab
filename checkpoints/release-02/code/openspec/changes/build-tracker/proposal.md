## Why

Команде нужен локальный сервис «Поток»: трекер задач и недельный планировщик загрузки в одном интерфейсе. Сейчас нет единого места, где видно, кто перегружен в неделю, какой прогресс у каждого и как разумно перераспределить работу. Сервис работает без backend, авторизации и внешних ресурсов.

## What Changes

- Новое приложение в `dist/`: `index.html`, `styles.css`, `app.js`, `domain.js` (локальный Tabler, без npm install).
- CRUD задач (название, описание, ответственный/«Без ответственного», оценка в часах, статус, неделя) с прикладной валидацией.
- Доска todo/doing/done с drag-and-drop и представление «по сотрудникам» на общих данных.
- Поиск и фильтр по ответственному; навигация по неделям (старт 2026-09-28), независимые задачи и доступность недель.
- Недельная доступность 0–168 ч для четырёх сотрудников; загрузка (активные/доступные, %, перегрузка) и прогресс (выполненные/все назначенные).
- Предложение распределения: предпросмотр, отмена, явное применение; ограничения по доступности.
- Сохранение в localStorage, устойчивость к повреждённым данным, восстановление seed после подтверждения.
- Адаптивность 390/768/1100/1280 px, подписи, клавиатура.

## Capabilities

### New Capabilities
- `tracker`: задачи, представления, недельная нагрузка и прогресс, планировщик, хранение, форма, UI.

### Modified Capabilities
- Нет (существующих спецификаций нет).

## Impact

- Новые файлы только в `dist/` (кроме `dist/vendor`, он не меняется).
- Публичный контракт `dist/domain.js` и `data-testid` — по `docs/INTERFACES.md`.
- Вне объёма: backend, авторизация, сеть, внешние шрифты/CDN, добавление сотрудников, история изменений, мультипользовательская работа.
