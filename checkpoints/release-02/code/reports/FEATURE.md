# Резерв интерактива

Подготовленная доработка после release-01. Переключатель оставляет видимой только перегруженную часть команды. Расчёты, задачи и метрики не меняются. В чистом примере видна только Анна, при следующей неделе — пустое состояние. Отключение возвращает всех сотрудников. Это резерв, а не результат нового запроса во время выступления.
