## 2. Исправленный дефект

- Было (sdd-09): правая граница aside=240, кнопок «Доска», «По сотрудникам», «Восстановить учебный пример»=256.24. Они заходили на основную область.

- Проверка (sdd-17, внешняя): на 1280 и 1100 px граница aside=240, границы трёх кнопок=223.33 (≤224). Дефект устранён.
- Ограничение: шириной 992–1023 и высотой окна проверка не занималась. Перенос текста «Восстановить учебный пример» в браузере глазами не подтверждён. Автотесты геометрию не проверяют, тест на эту регрессию не добавлялся.

## 3. Оставшиеся ограничения
**Не проверено в браузере (NOT RUN):**
1. Полный CRUD: создание, редактирование, удаление.
2. Drag-and-drop мышью (рамка drop-зоны, высота пустой колонки).
3. Повреждённый `localStorage` и перезагрузка с сохранением.
4. Клавиатура: порядок Tab, видимость фокуса, Esc, возврат фокуса.
5. UI-сценарии «План» (предпросмотр → отмена или применение) и «Сброс».
6. Основная область на 768 и 390 (кроме отсутствия переполнения); длинные данные (название 140 символов без пробелов, описание 1000, текст подтверждения).
7. Озвучка скринридером (`role=alert`, `aria-live`, `alertdialog`).

**Риск измерения:** `html, body{overflow-x:hidden}` (`styles.css:3`) скрывает переполнение, поэтому `scrollWidth` само по себе его не доказывает. Для боковой панели риск закрыт прямым измерением границ. Для основной области (карточки, таблица плана) такого измерения нет.

**Открытые замечания (по коду, после ревью не перепроверялись):**
- Средние: №2 порог 3 колонок на 992 даёт ≈229 px на колонку (<240 по плану); №4 у `#confirm-text` нет `overflow-wrap`, длинное название может выйти за 390 px; №5 (= QA O1) после закрытия формы, подтверждения и предпросмотра фокус уходит на `body`; №6 ошибка формы может оказаться ниже экрана на 390 px, поля не связаны с `task-error` через `aria-describedby`.
- №1 (nowrap у кнопки сброса) связан с D1; по коду закрыт правкой `.side-reset`, в браузере перенос не подтверждён.
- Низкие: O2 (`validateTask` принимает массив в `week` при прямом вызове API); O3 (`isValidState` принимает `employees: []`); неделя не сохраняется после перезагрузки; в виде «По сотрудникам» карточки `draggable` без зон сброса; у боковой панели нет `overflow-y:auto`.
