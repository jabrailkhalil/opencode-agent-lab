# Дополнительная итерация оформления

Подготовленная версия после сохранённого API-прогона. Общий план: docs/SPEC-UI-CONTRACT.md.

- Единая панель, шапка, метрики, карточки сотрудников, фильтры и доска.
- Одинаковая палитра, размеры, интервалы и адаптация для Sonnet и Qwen со спецификацией.
- Формулы dist/domain.js сохранены без изменений.
- Исходная версия: qspec-11; её код и скриншоты доступны отдельно.
- Эта итерация не добавляет запросов и токенов к историческим метрикам API.
- Визуальное сходство демонстрирует применение общего плана; оно не является измерением самостоятельной генерации двух моделей.
