# План реализации UI

## Общая структура

- **Корневой контейнер**: `app` с атрибутом `data-testid="app"`
- **Навигационная панель**: фиксированная высота, содержит заголовок и элементы управления
- **Основная область**: содержит метрики недели, переключатель представлений и активное представление
- **Представления**:
  - **Канбан-доска**: `board` с атрибутом `data-testid="board"`
  - **Представление по сотрудникам**: `employees-view` с атрибутом `data-testid="employees-view"`
- **Форма задачи**: `task-form` с атрибутом `data-testid="task-form"`, модальное окно
- **Модальное окно предпросмотра плана**: `plan-preview` с атрибутом `data-testid="plan-preview"`

## Элементы и их атрибуты data-testid

### Навигационная панель и управление неделями
- `current-week` - отображение текущей недели
- `prev-week` - кнопка перехода к предыдущей неделе
- `next-week` - кнопка перехода к следующей неделе
- `search` - поле поиска задач
- `filter-assignee` - выпадающий список фильтрации по ответственному

### Переключение представлений
- `view-board` - кнопка переключения на канбан-доску
- `view-employees` - кнопка переключения на представление по сотрудникам

### Метрики недели
Для каждого сотрудника (`employee-anna`, `employee-dmitry`, `employee-maria`, `employee-ilya`):
- Контейнер сотрудника: `employee-anna`, `employee-dmitry`, `employee-maria`, `employee-ilya`
- Загрузка: `load-anna`, `load-dmitry`, `load-maria`, `load-ilya`
- Прогресс: `progress-maria`, `progress-dmitry`, `progress-ilya`, `progress-anna`
- Поле доступности: `capacity-anna`, `capacity-dmitry`, `capacity-maria`, `capacity-ilya`

### Канбан-доска
- Колонки: `column-todo`, `column-doing`, `column-done`
- Кнопка создания задачи: `new-task` с атрибутом `data-testid="new-task"`
- Карточки задач: `task-TASK-101`, `task-TASK-102` и т.д.
- Кнопки редактирования и удаления задач: `edit-TASK-101`, `delete-TASK-101` и т.д.

### Представление по сотрудникам
- Строки/карточки сотрудников: `employee-anna`, `employee-dmitry`, `employee-maria`, `employee-ilya`
- Списки задач для каждого сотрудника

### Форма задачи
- `task-form` - контейнер формы
- `task-title` - поле ввода названия
- `task-description` - поле ввода описания
- `task-hours` - поле ввода оценки в часах
- `task-assignee` - выпадающий список выбора ответственного
- `task-status` - выпадающий список выбора статуса
- `task-week` - поле выбора недели
- `task-save` - кнопка сохранения
- `task-cancel` - кнопка отмены
- `task-error` - контейнер для отображения ошибок

### Планирование
- `propose-plan` - кнопка предложения плана
- `plan-preview` - модальное окно предпросмотра
- `plan-apply` - кнопка применения плана
- `plan-cancel` - кнопка отмены планирования
- `reset-demo` - кнопка сброса к демонстрационным данным

## Стили

- Использовать предоставленный локальный CSS Tabler из `dist/vendor/tabler/`
- Цвет акцента: #206bc4
- Цвет текста: #182433
- Цвет фона: #f6f7f9
- Цвет границ: #e6e8ec
- Цвет ошибок: #d63939
- Цвет завершения: #2fb344

## Адаптация

- Дизайн должен адаптироваться под следующие ширины экранов: 390px, 768px, 1100px, 1280px
- На всех разрешениях должны быть видны метрики нагрузки и прогресс каждого сотрудника
- Отсутствие горизонтального переполнения

## Состояния элементов

- **Активное состояние кнопок**: изменение фона или границы для визуального отклика
- **Состояние ошибки формы**: отображение сообщения об ошибке внутри формы, поля сохраняют введённые значения
- **Состояние загрузки**: отображение индикатора загрузки при выполнении операций
- **Состояние перегрузки**: числовое значение и подпись для перегрузки
- **Состояния drag-and-drop**: визуальные подсказки при перетаскивании задач между колонками
