# UI: решение дизайнера

Причина: правило четырёх колонок от 1250 px перезаписывает двухколоночную панель рядом с боковым блоком. Решение: сохранить две колонки, одну на узких экранах. Не менять формулы, тексты кнопок и testid. Проверять 390, 768, 1100, 1280 и 1920 px.

## Основание

Дополнительная подготовленная сцена по дефекту, обнаруженному после репетиции 7 октября. Проверка проведена в браузере. Этот материал дополняет исходную запись; он не является новым ответом API Claude и не входит в сравнение стоимости моделей.
